# NOVERA Studio — Site vitrine V1

## Contenu
- `index.html` : structure et textes du site.
- `style.css` : couleurs, mise en page et adaptation mobile.
- `script.js` : menu mobile, année automatique et démonstration du formulaire.

## Ouvrir le site sur Mac
1. Décompressez le dossier.
2. Ouvrez le dossier dans Visual Studio Code.
3. Ouvrez `index.html` dans votre navigateur (double-clic depuis Finder fonctionne aussi).
4. Pour une meilleure expérience de développement, vous pouvez installer l'extension Live Server dans VS Code.

## Avant une mise en ligne réelle
- Remplacer `contact@votre-domaine.fr` dans `script.js` par une adresse e-mail réellement créée.
- Remplacer les concepts fictifs du portfolio par des réalisations réelles ou les garder clairement identifiés comme concepts.
- Ajouter les mentions légales, une politique de confidentialité et les informations de l'entreprise.
- Configurer un véritable traitement de formulaire si vous souhaitez recevoir les demandes sans logiciel de messagerie.
- Vérifier les droits sur les images, textes, polices et autres contenus utilisés.
- Acheter/configurer un nom de domaine et choisir l'hébergement adapté.

Le formulaire de cette V1 ouvre un logiciel de messagerie : il n'envoie pas de données vers un serveur et ne constitue pas encore un système de formulaire en ligne.
